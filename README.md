# xrwvm-fullstack_developer_capstone

## Project Name: Car Dealership Full Stack Application

A full stack car dealership application built with Django, React, Express, MongoDB and a sentiment analyzer microservice deployed on IBM Code Engine.

**Repository name:** xrwvm-fullstack_developer_capstone

**Features**
- View dealerships and filter them by state
- View dealer details and customer reviews
- User registration, login and logout
- Post dealer reviews with sentiment analysis
- Car makes and models managed through the Django admin site
